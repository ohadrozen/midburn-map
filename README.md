# Midburn 2026 map with GPS

`index.html` is a self-contained Leaflet page: the wiseze.com city map georeferenced onto satellite imagery, with your phone's GPS position, an opacity slider and camp search. `midburn_map.kmz` is the same overlay for the Google Earth app.

Source files, the pixel-to-GPS transform and the build script live in `~/code/midburn_map/` (local). The map image belongs to the Midburn map team / wiseze.com.
